# مرجع llms.txt

ایندکس رسمی داک ابزارها، همان فایل `/llms.txt` هر سایت. برای جست‌وجو در داک کافی است. بدنهٔ کامل (`llms-full.txt`) این‌جا نیست؛ Nuxt و Nuxt UI آن را حدود یک میلیون توکن می‌دانند و باید از URL خوانده شود.

اگر این ایندکس با کد همین ریپو فرق داشت، `AGENTS.md` و `README.md` پوشه برنده است.

| ابزار | فایل | منبع | بدنهٔ کامل |
| --- | --- | --- | --- |
| Nuxt | [nuxt.txt](nuxt.txt) | https://nuxt.com/llms.txt | https://nuxt.com/llms-full.txt |
| Nuxt UI | [nuxt-ui.txt](nuxt-ui.txt) | https://ui.nuxt.com/llms.txt | https://ui.nuxt.com/llms-full.txt |
| Vue | [vue.txt](vue.txt) | https://vuejs.org/llms.txt | https://vuejs.org/llms-full.txt |
| Reka UI | [reka-ui.txt](reka-ui.txt) | https://reka-ui.com/llms.txt | https://reka-ui.com/llms-full.txt |
| Vite | [vite.txt](vite.txt) | https://vite.dev/llms.txt | — |
| Vitest | [vitest.txt](vitest.txt) | https://vitest.dev/llms.txt | — |
| Tailwind Variants | [tailwind-variants.txt](tailwind-variants.txt) | https://www.tailwind-variants.org/llms.txt | https://www.tailwind-variants.org/llms-full.txt |

Tailwind CSS، TypeScript و ESLint فایل `llms.txt` منتشر نکرده‌اند. Tailwind v4 در اسکیل `tailwindcss` است. `tailwind-merge` هم ایندکس llms ندارد.

اسکیل‌های نصب‌شده در `.agents/skills/` و قفل نسخه در `skills-lock.json` است.
